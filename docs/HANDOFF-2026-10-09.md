## Local build and test setup

- **Playwright:** it is not installed in this repo. Set `PLAYWRIGHT_PATH` to the copy in the SurBEE project:
  `C:\Users\jrosp\Documents\Claude_SurBEE-App\tests\node_modules\playwright-core`.
- **pnpm:** it is no longer installed globally. pnpm 11.19.0 is in corepack's user cache; the user approved that download. To make `pnpm run dist` work, put a `pnpm.cmd` containing `@corepack pnpm@11.19.0 %*` on `PATH` and set `COREPACK_ENABLE_DOWNLOAD_PROMPT=0`.
- **GitHub CLI:** `gh` is signed in as jrosprs7 (keyring), which the user did. `git push` uses the stored Git credentials.
- **Tests:** the list is in the testing guide. This session ran every root test, every browser smoke and every desktop smoke, plus the editor suites with `--desktop`, before each commit. `desktop/prepare.cjs` must run before any Electron check.
- **Release procedure used:**
  1. Bump `desktop/package.json` and the README version line, then run `pnpm run dist`.
  2. Extract `app.asar` and byte-compare its files with the sources.
  3. Rerun shell-ui-smoke.cjs.
  4. Commit the build record and push.
  5. Point the README download link at the new tag, then commit and push.
  6. Run `gh release create vX --prerelease` with only the Setup.exe and notes in the style of earlier releases.
  7. Download the asset anonymously and compare its SHA-256.
  8. Record the publication in the changelog, then commit and push.

## Local build and test setup

- **Playwright:** not installed in this repo. Set `PLAYWRIGHT_PATH` to the SurBEE copy: `C:\Users\jrosp\Documents\Claude_SurBEE-App\tests\node_modules\playwright-core`.
- **pnpm:** not installed globally. pnpm 11.19.0 is in corepack's user cache. For `pnpm run dist`, put a `pnpm.cmd` containing `@corepack pnpm@11.19.0 %*` on `PATH` and set `COREPACK_ENABLE_DOWNLOAD_PROMPT=0`.
- **asar extraction** (for payload checks): use the module electron-builder installs, `desktop/node_modules/.pnpm/@electron+asar@3.4.1/node_modules/@electron/asar` (`extractAll`). `npx asar` is not available offline.
- **GitHub CLI:** `gh` is signed in as jrosprs7. `git push` uses the stored Git credentials.
- **Full suite:** the testing guide lists the commands. In every session the full set has been run before each commit:
  - all root tests;
  - every browser smoke (now including sidebar-smoke.cjs and large-paste-smoke.cjs);
  - the editor suites (list-interactions, tab, highlight, dash, font, quote-literal, bullet-literal, data-safety, scroll-position, sidebar) with `--desktop`;
  - every remaining desktop smoke, after `node desktop/prepare.cjs`.
- **Electron 44 notes:**
  - The main-process `clipboard` is async and has only `readText`, `writeText`, `read`, `write`, `has` and `clear`; `readHTML` and `availableFormats` are gone.
  - Electron's viewport can be fractionally wider than `innerWidth`, so use range media queries such as `(width < 900px)` rather than `max-width: 899px`.
- **Native popups** (select lists, context menus) are not in Playwright screenshots. Context menus are captured in the main process (see context-menu-smoke.cjs). Select lists were checked once by capturing the screen with System.Drawing.
- **Root tests evaluate slices of Rotepad.html.** For example, tests/library.cjs runs the code from `const uid=` up to `function applyPrefs` in a Node sandbox without browser APIs. Do not put browser-only top-level code in such ranges.
- **Release procedure** (used for 0.12.x; step 6 changed for 0.13.0, whose installed copies update from GitHub releases; see the [desktop guide](../desktop/README.md#updates)):
  1. Bump `desktop/package.json` and the README version line, then run `pnpm run dist`.
  2. Extract `app.asar` and byte-compare its files with the sources.
  3. Rerun shell-ui-smoke.cjs and the smoke for the change.
  4. Commit the build record and push.
  5. Point the README download link at the new tag, then commit and push.
  6. Run `gh release create vX --prerelease` with dist/Rotepad-X-Setup.exe, dist/latest.yml and dist/Rotepad-X-Setup.exe.blockmap, keeping their built names; installed 0.13.0+ copies find updates through latest.yml. As before, the portable exe is not attached. Write notes in the earlier style, and include unreleased intermediate versions.
  7. Download the assets anonymously and compare the Setup.exe SHA-256, and check that the downloaded latest.yml names that Setup file.
  8. Record the publication in the changelog, then commit and push.

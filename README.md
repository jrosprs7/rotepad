# Rotepad

An offline writing app for Windows: formatted editing or Markdown source, a note library with tabs,
search, history and backups. Your notes stay on your PC.

## Download

**[Open the releases](https://github.com/jrosprs7/rotepad/releases)**: in the newest release, open
**Assets** and choose the file ending in `-Setup.exe`.

- Windows 10 or 11 (64-bit). No administrator rights needed; Rotepad installs for your account only.
- Windows may show "Windows protected your PC" because the installer isn't code-signed yet: choose
  **More info → Run anyway**.
- Once installed, Rotepad checks for a new version when it starts and asks before restarting to
  update (Menu → Help → Check for updates…).
- Releases are testing previews.

## What's new
